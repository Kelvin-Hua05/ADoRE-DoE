# Phase 5：Module 2 ML 殘差修正

```
y_final(x) = y_RSM(x) + λ · e_ML(x),      eᵢ = yᵢ − y_RSM^(OOF)(xᵢ)
```
範圍：OOF 殘差目標、GP / MLP / SVR 殘差模型、「不修正」回退、λ（`auto` 或固定值）、混合模型、獨立驗證集評估。
**不做**：Random Forest（ADR-011：視研究結果再加入；注意 README 的 v0.5 條目與 Roadmap 仍寫了 RF，我依已 Accepted 的 ADR-011 處理）、轉換 / WLS（延後）。
**獨立性（ADR-005）**：`residual` 不 import `active_learning`（有測試）；它只依賴 `core` 與 `rsm`。需要 scikit-learn（`pip install "adore-doe[ml]"`）；沒有安裝時套件仍可 import，使用學習器時才會得到明確的安裝提示。

## 1. API

```python
from adore_doe import residual

h = residual.fit(ds, "Capacitance", model="quadratic",
                 selection={"method": "stepwise", "criterion": "p"},   # 選填：每一折內重做選項
                 learners=("gp", "mlp", "svr"), lam="auto", min_gain=0.05, seed=7)
h.predict(Z); h.predict_rsm(Z); h.learner_name; h.lam; h.report            # report：各學習器的比較
h.evaluate(Z_val, y_val)                    # 獨立驗證資料上的 RSM vs 混合：RMSE / MAE / R²
all_models = residual.fit_responses(ds, ["C", "R", "Delay"], seed=7)       # 每個響應各自建模
```

## 2. 方法

1. **OOF 殘差**：重複 5 折（預設 3 次重複）；每一折都用該折訓練資料**重新擬合 RSM，包含項選擇**；`eᵢ = yᵢ − mean_r ŷᵢ^(−fold)`。折內不可識別的模型以「刪除被混淆的項」修復並計數（`info["n_folds_with_dropped_terms"]`），不用偽逆。
2. **學習器比較**：對每個候選學習器，在 `(xᵢ, eᵢ)` 上做 K 折交叉驗證得 OOF 殘差預測 `êᵢ`，比較 `RMSE(e − λê)` 與「不修正」`RMSE(e)`。`λ = auto`：`λ* = clip(Σeê/Σê², 0, 1)`。
3. **回退**：最佳學習器的相對增益 < `min_gain`（預設 5%）→ 不修正（`λ = 0`，混合模型 = RSM）。
4. 最終：RSM 以全部資料擬合；所選學習器以 OOF 殘差擬合。

| 學習器 | 設定 |
|---|---|
| `gp` | scikit-learn GP，常數 × Matérn-5/2（ARD）+ White 噪音，邊際似然 |
| `mlp` | 單隱藏層（8，tanh）、L2 = 1.0、L-BFGS |
| `svr` | RBF；C ∈ {0.1, 1, 10, 100}、ε ∈ {0.01, 0.1} 以內層 5 折 CV 選擇 |

目標值在內部標準化；所有學習器接受顯式 seed，同 seed 同結果。

## 3. 驗證實驗（驗收項目；合成資料）

`examples/phase5_residual_experiment.py`：3 因子；真值 = 二次多項式 + 結構性殘差（RSM 無法表示）+ 噪音（sd 0.05）；訓練為 Latin hypercube（n = 30 或 45，每個 seed 不同）；獨立驗證集 1024 個 Sobol 點（不參與任何擬合）；20 個 seed。驗證 RMSE（平均 ± 標準差）：

| 情境 | n | RSM | 混合（本套件） | 一律 GP 修正（不比較） | 混合 − RSM | 混合退回「不修正」 |
|---|---|---|---|---|---|---|
| smooth 結構性殘差 | 30 | 0.451 ± 0.031 | 0.365 ± 0.091 | 0.335 ± 0.057 | −0.085（13 較好 / 0 較差） | 7/20 |
| smooth 結構性殘差 | 45 | 0.431 ± 0.042 | 0.190 ± 0.037 | 0.185 ± 0.030 | −0.241（20 / 0） | 0/20 |
| 局部峰 | 30 | 0.309 ± 0.022 | 0.286 ± 0.051 | 0.270 ± 0.044 | −0.023（6 較好 / **2 較差**） | 12/20 |
| 局部峰 | 45 | 0.282 ± 0.024 | 0.171 ± 0.059 | 0.161 ± 0.056 | −0.111（19 / 0） | 1/20 |
| 純二次（無結構） | 30 | 0.034 ± 0.011 | 0.034 ± 0.011 | 0.044 ± 0.016 | **0.000（0 / 0）** | 20/20 |
| 純二次（無結構） | 45 | 0.026 ± 0.006 | 0.026 ± 0.006 | 0.031 ± 0.005 | **0.000（0 / 0）** | 20/20 |

**如實的結論**：
* **沒有結構時不會變差**：40 次裡 40 次回退成純 RSM（驗證誤差完全相同）；不比較、一律用 GP 修正的做法則在 16/20 與 19/20 的 seed 下變差。回退機制有價值。
* **有結構且樣本足夠（n = 45）時明顯改善**：驗證 RMSE 從 0.431 → 0.190、0.282 → 0.171。
* **樣本少（n = 30）時效果有限**：smooth 情境 13/20 改善、局部峰只有 6/20 改善，且有 **2/20 變差**——小樣本下學習器學不起來，回退也不是百分之百可靠。
* **回退偏保守**：有結構的情境中，混合的平均表現略遜於「一律 GP」（例如 n = 30 smooth：0.365 對 0.335），這是用 `min_gain` 換來「無結構時不傷害」的代價。
結果只適用於這幾個函數與設定，不應推廣；完整的四組比較屬於 Phase 6。

## 4. 限制（誠實聲明）

* **殘餘樂觀偏差**：殘差目標 `eⱼ` 由「看過其他 run 響應」的折內 RSM 產生，所以內層的學習器 / λ 比較並非完全獨立的估計。**請一律以獨立驗證資料評估混合模型**（`evaluate`）。
* OOF 的重複次數（預設 3）與 `min_gain`（5%）是預設值，尚未最佳化（ADR-006 的開放問題）。
* 自行實作的是流程；GP / MLP / SVR 來自 scikit-learn，未做跨版本數值鎖定。
* 小樣本（< 6 個 run）直接報錯；沒有針對單一響應以外的聯合修正。
